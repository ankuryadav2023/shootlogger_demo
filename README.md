# ShootLogger — Refined Demo

Plain HTML, CSS and JavaScript. No framework or build step required.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Features
- Minimal black-and-white interface on a light background
- Compact-radius design system and Lucide icons with tooltips
- Event stats, add/view/edit/delete events
- Search plus event type, camera, and date filters
- Sort newest-first, oldest-first, or by video timestamp
- Delete all events with confirmation
- CSV export and sample events
- Persistent browser `localStorage`

This is a frontend-only demo. Data stays in the browser where it was added. Lucide icons and Google Fonts load from CDNs.
